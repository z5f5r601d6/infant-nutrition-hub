# 【朝医新闻】常营院区营养科体重管理营养门诊开诊啦

> 更新时间：2026-09-17 (UTC+8)

近日，26岁的小杨（化名）来到北京朝阳医院常营院区营养科体重管理营养门诊就诊。小杨身高180cm，体重却将近120公斤。营养科认真询问了小杨的饮食情况，发现小杨平常以肉食为主，不喜欢吃蔬菜，偏爱各种零食、甜点和饮料，还经常熬夜，不爱运动。

主管营养师段云卉给小杨开具了血脂、血糖、肝肾功能等相关化验检查，并进行了人体成分检测。结果显示，小杨的体脂率达到了31.6%，内脏脂肪指数为15.4，被判定为肥胖II级。

段云卉建议小杨积极改善生活方式，做到早睡早起，改善膳食结构，增加谷薯类、绿叶蔬菜的摄入，减少高能量高脂肪类食物的摄入，并鼓励小杨戒断零食和饮料。段云卉还通过诊桌上的食物模型，详细地为小杨进行了一日三餐的膳食推荐量讲解，并教会小杨如何做饮食日记和运动日记。

从门诊出来的小杨满面笑容：“这个体重管理营养门诊太贴心了，回去我一定会按照这个饮食方案执行，希望能尽早减掉体重。”

为积极响应“体重管理年”行动号召，进一步发挥营养科专业技术优势，满足市民对专业化体重管理的需求，朝阳医院常营院区营养科于4月初开设了体重管理营养门诊。该门诊聚焦个性化营养干预，结合生活方式指导，为超重/肥胖及慢性代谢性疾病患者提供个性化体重管理方案。即日起，患者可通过官方渠道预约就诊。

门诊硬件设备及环境

门诊配备人体成分分析仪、孕期人体代谢检测仪、食物模型等先进仪器设备，能够对肥胖患者身体状态进行全面、精准的评估，通过体成分和代谢指标的检测，结合BMI指数、腰围等数据，科学判断肥胖程度、脂肪分布情况及代谢状态，为制定个性化的体重管理方案提供科学依据。针对不同人群（如青少年、孕产妇、慢性代谢性疾病患者等）进行食谱制定、体重管理及长期随访方案，确保体重管理期间营养均衡。
**一、适用人群**
1. BMI≥24（超重）或BMI≥28（肥胖）者；

2. 单纯性肥胖、糖尿病、脂肪肝、高脂血症等代谢性疾病患者；

3. 孕期/产后体重管理、多囊卵巢综合征患者；

4. 儿童青少年肥胖防控对象；

5. 反复节食无效、渴望科学减重的人群；

6. 术后康复、肌少症患者。
**二、就诊须知**
1. 首次就诊建议空腹，需完成血常规、肝肾功能、血糖血脂等基础检查（部分项目需提前预约）。

2. 携带资料：近期体检报告、饮食日记（如有）、运动习惯记录等。

3. 随访机制：医生将根据减重进度动态调整方案，建议定期复查（如每2周一次）。
**三、门诊信息**
1. 门诊地址：常营院区门诊楼综合四诊区24诊室。

2. 门诊时间：周四上午**。
