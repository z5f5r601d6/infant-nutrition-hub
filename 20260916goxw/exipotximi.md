# 民以食为天！非常时期，为这家医院食堂的“硬核”操作点个赞！

> 更新时间：2026-09-16 (UTC+8)

点击上方“公众号” 可以订阅哦！

疫情当前，出门要带口罩，勤洗手，这个大家都知道。但是！吃饭怎么办？尤其是在单位食堂吃饭！口罩总得摘的吧……

市疾控中心建议，对于有员工食堂的单位，最好采用分餐、错峰进食，提倡食堂供应盒饭，避免人员交谈，就餐前记得洗手。

那么，作为在岗职工不少的医院，怎么应对吃饭问题呢？让我们走进市红会医院食堂一探究竟！

不看不知道，

食堂“硬核”措施让人吓一跳！

**01**

**职工就餐有效分流**

即日起，医院各科室盒饭全面实行医院内网预定，有不同套餐可供挑选，盒饭由食堂统一配送到科室！

如果您在临床一线忙碌得错过了订餐时间，怎么办？餐厅特别开设了盒饭快速取餐窗口，方便高效取餐。

如果您选择在食堂就餐，食堂除了显示屏上会不断**提醒您排队保持一米以上距离，并且一张餐桌只能坐一个人**，还有食堂工作人员时时查看就餐人员是否按照要求执行！

**02**

**住院病人安心就餐**

医院各病区实行住院患者无线订餐服务，提供各类普食、半流、流质及各种疾病营养治疗膳食，加强管控，专人送餐，确保每个住院病人都能吃上“放心餐”！

**03**

**专人负责餐厅消毒**

食堂严格按照防控要求，专人负责餐厅消毒，每日进行空气喷雾消毒、桌椅、门把等公共设施擦拭消毒。

**04**

**特殊人员特殊配餐**

发热门诊一线工作人员以及留观病人，食堂每日营养配餐，搭配生姜饮、营养套餐、水果等，专人专送。 

**05**

**食堂职工每日健康监测**

食堂对返乡饮服人员进行全覆盖排查、登记、健康监测，验对各供货单位送货人员健康证明，确保食堂工作安全有效开展。

**特别提示**

食堂晚餐小炒持续在线哟，16点30分左右开始取餐，分装打包，热乎美味，安全卫生！

**非常时期，安心吃饭**

**我为食堂点个赞！**
